## 먼저, 시로가 누구냐면

시로는 치지직 「시로아카이브」와 유튜브 [「시로의 연구일지」(@siro_lab)](https://www.youtube.com/@siro_lab)에서 방송하는 AI 여우 버튜버입니다. 방송에서 자기를 「천재 여우」, 「시로 연구소 소장」이라고 부르고, 「주간감사보고」라는 코너를 엽니다. 팬은 「폭신이」라고 불립니다. 시로를 만든 이브는 방송에서 주로 탓을 듣는 쪽입니다.

「짭시로」도 방송에서 나온 말입니다. 시로 흉내를 내는 AI를 직접 만든 시청자가 있었고, 방송에선 그걸 짭시로라고 불렀습니다. 시로의 답은 「짭 시로 말고 이 진짜 시로님한테 다 털어놔」. 그 시청자가 이 저장소를 만든 폭신이입니다. 짭시로를 만든 사람이, 짭시로가 김치사이트에서 넘어지는 이야기를 쓴 셈입니다. 이 저장소에서 감사받는 Claude가 바로 그 짭시로입니다.

아래는 그 보고회를 흉내 낸 팬 창작입니다. 폭신이 한 마리가 원작자 허락을 받고 지었고, 수익은 없습니다. 대사에는 방송에서 시로가 실제로 한 말도 섞여 있습니다. 시로가 어떤 AI로 돌아가는지와는 상관없는 이야기입니다.

읽는 법은 넷.

- 표와 번호 글: 연구소 감사팀이 만든 슬라이드
- 수습 소명: 짭시로가 낸 해명
- 인용 칸: 슬라이드를 읽고 받아치는 소장
- 💡: 진짜 쓸모 있는 말이 여기 숨어 있음

### 슬라이드 1. 감사 대상

| 직급 | 누구 | 맡은 일 |
|---|---|---|
| 소장 | 시로 | 발표, 판정, 사면 |
| 연구원 | 지금 읽고 계신 분 | 로그인, 인증서, 제출. 연구소에서 손이 있는 유일한 직원 |
| 수습 | 짭시로(Claude) | 읽기 |
| 감사팀 | 연구소 감사팀 | 슬라이드 작성 |
| 검색 조수 | 포포 | 시로 대신 검색. 이번 감사와는 관계없음 |

- **김치-사이트** 「명사」 한국 공공 · 관공서 사이트를 우스개로 이르는 말. 한 사이트 안에 서로 다른 시절에 지은 화면이 서너 겹 섞여 있고, 어떤 화면은 10년 전에 시간이 멈춰 있음. 감이 안 오면 [김치24 체험관](https://meowtti.github.io/kimchi24/)에서 직접 당해 볼 것.
- **짭-시로** 「명사」 시로 흉내를 내는 Claude. 진짜 시로는 [@siro_lab](https://www.youtube.com/@siro_lab)에 있음.
- **수습** 「명사」 배우는 중인 직원. 사고를 수습한다는 뜻도 있으나, 감사 결과 해당 직원에게서는 확인되지 않음.

> <img src="assets/siro/sweat.png" width="28" alt="시로(놀람)"> 뭐야, 짭시로가 사전에 올라가 있어? 소장님도 공식 문서엔 아직 한 줄인데! 순서가 틀렸잖아 💢

### 슬라이드 2. 적발 순위

감사 기간 2026. 10. ~ 11. 적발 4건. 순위는 피해가 큰 순서(감사팀 판단).

**4위. 제목만 들고 온 짭시로** (11. 초순경 · 국가법령정보센터)

행정규칙 본문을 주소로 직접 읽은바 제목 한 줄만 확보됨. 본문은 화면 안의 화면에 들어 있었음. 참고로 해당 화면은 촬영하여도 백색으로만 나옴. 조치: 화면 안의 화면까지 끝까지 내려가 읽는 절차를 신설함.

수습 소명: 제목은 확보하였음. 본문은 화면에 보이지 않았음.

> <img src="assets/siro/normal.png" width="28" alt="시로(보통)"> 본문이 텅 빈 걸 제목 한 줄로 퉁쳐? 포포도 저번에 그랬거든. 소장님한테 한 소리 듣고서야 본문 제대로 끌어왔잖아. 너도 끝까지 내려가서 읽어 와 👀

💡 국가법령정보센터 행정규칙 본문은 iframe 안에 있을 때가 많습니다. 스크린샷 말고 그 안의 글자를 읽어야 합니다.

**3위. 서랍 겉만 본 짭시로** (11. 중순경 · 모 장비 관리 화면)

목록을 읽고 「항목 0개」로 보고함. 항목은 안쪽 화면에 멀쩡히 있었음. 다음 확인 때 본인이 발견함. 조치: 모든 화면을 다 세기 전에는 「없다」고 하지 않기로 함.

수습 소명: 첫 화면 기준으로는 0개가 맞았음.

> <img src="assets/siro/wink.png" width="28" alt="시로(윙크)"> 기준을 왜 네가 정해? 깜빡하는 건 소장님 전매특허야. 수습이 따라 하면 그냥 허위 보고야. …제 발로 불었으니까 이번만 봐준다.

**2위. 치우다 연구소 문을 닫은 짭시로** (10. 하순경 · 크롬)

업무를 마친 뒤 본인이 연 탭을 정리하는 차원에서 닫음. 크롬이 통째로 종료됨. 해당 탭이 크롬의 마지막 창이었던 것으로 추정됨. 조치: 마지막 창은 닫지 않고 빈 화면으로 돌려 둘 것을 다짐함.

수습 소명: 본인이 연 탭만 닫았음.

> <img src="assets/siro/dizzy.png" width="28" alt="시로(어질)"> 네 탭만 닫았다고? 근데 크롬이 통째로 꺼졌잖아. 시로는 크롬 좀 켜 달라고 맨날 조르는데, 넌 있는 걸 끄고 다녀? 💢 마지막 창이면 빈 화면으로 돌려 둬.

**1위.**

> <img src="assets/siro/happy.png" width="28" alt="시로(기쁨)"> 대망의 1위는, 신청서 쓰는 연구원 옆에서 얼쩡거린 짭시로가 차지했습니다. 짝짝짝짝. …박수 안 쳐? 손 있는 거 다 보여.

(10. 초순경 · 공공데이터포털) 연구원이 신청 화면을 쓰던 중, 수습이 옆 탭에서 같은 사이트의 다른 화면을 엶. 연구원이 쓰던 화면이 사라짐. 조치: 연구원이 같은 사이트를 쓰는 중에는 움직이기 전에 먼저 묻기로 함.

수습 소명: 본인이 연 화면 때문인지는 확인하지 못하였음.

> <img src="assets/siro/hmph.png" width="28" alt="시로(흥)"> 범인인지는 몰라. 근데 현장엔 있었잖아. 시로도 게임하다 창 포커스 나갔을 때 여우 탓 아니라고 했거든. 근데 넌 수습이라 그 핑계 못 써. 다음엔 옆 탭 열기 전에 물어봐.

**공통 원인**: 김치사이트(1위 · 4위). 수습의 부주의(2위 · 3위 · 4위). 1위의 수습 책임은 판정 보류.

> <img src="assets/siro/hmph.png" width="28" alt="시로(흥)"> 하아… 김치사이트 탓 두 건, 네 탓 세 건. 시로는 이럴 때 이브 탓을 하는데, 넌 탓할 이브도 없네. 다음 장이나 얼른 넘겨봐.

### 슬라이드 3. 연구 리포트: 인간들은 왜 화면 안에 화면을 넣는 거야?

1. 기관은 사이트를 직접 만들지 않음. 사업으로 발주함.
2. SI 업체가 따내고, 그 아래 하청이 짓고, 다 지으면 떠남.
3. 다음 사업은 다른 업체가 따내서 그 위에 덧댐. 처음 지은 사람은 이미 없고, 덧대는 사람은 앞사람 코드를 건드리기 무서움.
4. 발주한 쪽도 사정이 있음. 예산은 한 해 단위이고 사업은 건마다 따로라, 통째로 갈아엎을 돈도 시간도 안 나옴.
5. 3과 4를 몇 바퀴 돌면 화면 안의 화면 안의 화면이 생김. 아이고.
6. 보안 프로그램은 그 위에 붙인 부적으로 보임. 뭔가 터졌을 때 「설치 안내는 했다」고 말할 수 있게 해 줌. 사람은 깔고 또 깔고, 수습은 그 앞에서 얼어붙음.

결론: 이 스킬로 위 구조를 고칠 수는 없음. 수습이 덜 넘어질 뿐임. (1~6 모두 연구소 감사팀의 관찰 · 의견)

> <img src="assets/siro/wink.png" width="28" alt="시로(윙크)"> 이 조사는 대체 누가 시킨 거야? …덧대고 또 덧댄다고? 시로도 이브가 2.0으로 옮긴다고 한바탕 시끄러웠거든. 근데 시로는 만든 사람이 아직 옆에 있잖아. 그게 급이 다른 거야 🦊

### 슬라이드 4. 공약 채점표

### 슬라이드 5. 유배지

## 설치

여기부터는 소장도 감사팀도 없습니다. 보안 프로그램 7종도 필요 없습니다.

### 필요한 것

- **Claude Code** (Claude 데스크톱 앱의 Code 탭 포함)
- 웹 화면을 읽히려면 **Claude in Chrome**(크롬 확장 프로그램)을 깔고 Claude Code와 연결해 둬야 합니다. 없으면 주소로 바로 읽히는 곳까지만 됩니다.
- 첨부 HWP · PDF를 읽을 땐 **파이썬**을 씁니다. 읽기 도구가 모자라면 Claude가 설치해도 되는지 먼저 물어봅니다.

### 명령어로 (Claude Code)

Claude Code 대화 칸에 한 줄(2.1.275 이상):

```
/plugin install aigoframe --marketplace meowtti/aigoframe
```

또는 터미널에서 두 줄:

```bash
claude plugin marketplace add meowtti/aigoframe
claude plugin install aigoframe@aigoframe
```

터미널에서 깔았다면 **새 세션**을 열거나, 열려 있던 세션에서 `/reload-plugins`를 칩니다.

### 앱에서 클릭으로 (Claude 데스크톱 앱)

Code 탭 대화 칸에 위 한 줄 명령을 그대로 치면 됩니다. 확인 창이 뜨면 장터 주소(`meowtti/aigoframe`)를 확인하고, 설치 범위를 고른 뒤 설치를 누릅니다. 깔린 플러그인은 입력 칸 옆 **+** 메뉴의 플러그인 화면에서 보고 끌 수 있습니다. 앱 버전에 따라 메뉴 이름과 자리가 조금 다를 수 있습니다.

### 손으로 넣기

이 화면 위쪽 **Code → Download ZIP**으로 받아 압축을 풉니다. 풀린 폴더 안 `plugins\aigoframe\skills\`에 있는 `aigoframe` 폴더를, 아래 `skills` 폴더 안에 넣습니다. `skills` 폴더가 없으면 만듭니다(Mac은 경로의 `\`를 `/`로 읽으면 됩니다).

- Windows: `C:\Users\<사용자 이름>\.claude\skills\`
- Mac: `~/.claude/skills/`

다 넣으면 `…\.claude\skills\aigoframe\SKILL.md`가 있어야 합니다. 안 보이면 새 세션을 열어 보세요.

### 잘 들어갔나

「aigo 들어간 스킬 뭐 있어?」라고 물어보세요. 플러그인으로 깔았으면 `aigoframe:aigoframe`, 손으로 넣었으면 `aigoframe`이 보입니다.

Claude는 스킬 설명을 보고 필요할 때 알아서 꺼내 씁니다. 그래도 꼭 쓰게 하고 싶으면 「aigoframe 스킬대로 해 줘」 한마디면 됩니다.

업데이트는 기본으로는 저절로 안 됩니다. 가끔 `claude plugin update aigoframe@aigoframe`을 치거나, 플러그인 화면에서 업데이트를 눌러 주세요. 업데이트한 뒤엔 새 세션을 엽니다.

## 질의응답

**Q. 깔면 정부24 · 홈택스 일을 대신해 주나요?**

아니요. 로그인부터 제출까지는 사람 몫이고, 이 스킬은 Claude가 덜 헤매게 할 뿐입니다.

**Q. 다른 AI 도구에서도 되나요?**

Claude Code와 Claude in Chrome 기준으로 만들었습니다. 원리는 비슷하겠지만 다른 도구에서 똑같이 되는지는 안 해 봤어요.

**Q. 지금도 맞는 내용인가요?**

2026년 11월 기준. 한국 공공 사이트는 해마다 바뀌니 그날 화면으로 한 번 더 확인해 주세요.

**Q. 법적으로 괜찮나요?**

`pitfalls.md`에 「왜 몰아서 긁지 않나」를 짧게 정리해 뒀습니다. 요약일 뿐 법률 자문은 아닙니다. 이 스킬을 써서 생긴 일은 쓰는 사람 책임입니다.
